# Personal Expense Tracker

A simple console-based expense tracker built with Python.

## About the Project

This is my first Python project. I built it to practice Python fundamentals and learn how to store, retrieve, process, and display data using files.

## Features

- Add and manage expense records by category.
- Save expense data to a file.
- Load previously saved expenses.
- Calculate total expenses.
- Generate a readable expense report in a separate file.

## Technologies Used

- Python
- File handling
- Lists and dictionaries
- Functions
- String formatting

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in a terminal.


## What I Learned

- Working with Python lists and dictionaries.
- Reading from and writing to files.
- Converting saved data back into Python objects.
- Using functions to organize program logic.
- Formatting output into readable columns.
- Debugging errors and improving my code.
